## Stack Tecnológico
El proyecto **Apañao** está desarrollado utilizando el stack **MERN**:

- **MongoDB**: Base de datos NoSQL para almacenar toda la información de la aplicación.
- **Express.js**: Framework para Node.js que permite crear la API REST de forma sencilla y escalable.
- **React**: Biblioteca para construir interfaces de usuario interactivas y reactivas.
- **Node.js**: Entorno de ejecución para JavaScript en el servidor.
